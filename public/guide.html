What to install

Start with Always Active Window – Always Visible ↗. Its publisher claims visibility property, visibility event, blur and mouseleave coverage.

  1. Install from the Chrome Web Store in a separate profile.
  2. Open this checker and click the extension's action button to enable this hostname. The publisher says the page reloads and the icon turns blue.
  3. Repeat your actions and export the log.

Alternative: Disable Page Visibility ↗ for visibility and blur events. Use its popup to control this site and reload. Install one extension at a time.

Read the signals

Focus and visibility are different. A page can be visible while the address bar or another window has focus. A pointer leaving the page does not establish a tab switch.

Duration counters sample document properties. Suppressed events plus background timer throttling can hide transitions between samples and undercount time. The window-focus row shows the last observed event; compare it with sampled hasFocus().

Timer gaps measure scheduling delays. CPU load, sleep and browser policies can all increase them.

Screen sharing requires your approval. The preview stays in the page; nothing is recorded or uploaded. Fullscreen tracks the JavaScript API, separately from browser F11 mode.

A missing event means this page did not observe it. Other frames and scripts can behave differently. This page cannot inspect native application monitoring.
